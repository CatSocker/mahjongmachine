# 牌张区域

## 宝牌指示区

- 宝牌指示区 37*5 bool通道 每展开一张宝牌指示牌，在 37 个 bool 通道里面选一个置为 1。其余为 0。宝牌指示牌最多五张。

## 每名玩家独有区域

- 手牌 37*4 bool通道 每有一张特定类型的牌，在对应通道里置 1。其余为 0。
- 副露区 37*4 bool通道 每有一张特定类型的牌，在对应通道里置 1。其余为 0。
- 打牌区 37*25 bool通道 每有一张特定类型的牌，在对应通道里置 1。其余为 0。第 38 个通道用于记录摸切或手切。摸切置1，手切置0。

## 对于每一名玩家而言的公开信息包括：

- 自家手牌 37*4
- 所有四家的副露区 37*(4*4)
- 所有四家的打牌区 37*(25*4)
- 宝牌指示区 37*5

# 混合通道区域

- 场顺 2位bool通道。东场为 00，南场为 01，西场为 11。
- 当前局顺 2位bool通道。1局为 00，2局为 01，3局为 10，4局为 11。
- 是否是亲家 1位bool通道。是亲家为 1，子家为 0。
- 当前顺位 2位bool通道。当前为1位是00，2位01，3位10，4位11。
- 自家剩余亲权数（不计西入） 2位bool通道。2次亲机会为 00，1次为01，0次为11。
- 是否听牌与立直 2位bool通道。 未听牌 00，听牌 10，立直 11。
- 手牌向听数 8+6+13 bool通道 分别是玩家手牌距离一般型听牌、七对子听牌、国士无双听牌的向听数。每减少一向听，就在每个通道组内（8/6/13）最左侧不是1的位置，由0置1。

- 剩余牌张数 int通道。注意：每开一次杠，剩余牌张数也要减1。
- 供托点数 int 通道，单位百。实际上是供托区 本场棒数量*3 + 立直棒数量*10
- 自家点数 int 通道，单位百。
- 向上点差 int 通道，单位百。为自家和顺位仅高于自己一个顺位的玩家的点差，通常为负值或0。如果自家是1位，则置0。
- 向下点差 int 通道，单位百。为自家和顺位仅低于自己一个顺位的玩家的点差，通常为正值或0。如果自家是4位，则置0。
- 其他三家点数 三个 int 通道，单位百。为自家位置开始，逆时针顺序的三名其他玩家的点数。
